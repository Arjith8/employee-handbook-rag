6. Security

Badge required. Fridge code FRIDGE-00-PIZZA. Laptop encryption mandatory.

Security is everyone's job. Use a password manager, enable 2FA everywhere, and lock your laptop when you leave your desk. Report phishing with the one-click button. Do not plug unknown USB drives. The Northpole fridge code changes quarterly — do not write it on sticky notes.

Laptops are encrypted and remotely wipeable. Lost device? Report within 2 hours to security@zorgleflap.test. Production access needs ticket + approval + expiry. Customer data never goes on personal devices. Whatever whatever — when unsure, ask security before you click.

Office badges are personal. Tailgating is prohibited even if the person behind you is carrying three pickle pizzas and looks trustworthy. Visitors must sign in and be escorted. We strive for excellence in keeping secrets secret.
